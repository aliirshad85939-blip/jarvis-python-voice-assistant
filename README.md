# 🤖 Jarvis Python Voice Assistant

A Python-based voice assistant that can listen to voice commands and perform different tasks using speech recognition and automation.

## ✨ Features

- 🎤 Voice command recognition
- 🔊 Text-to-speech responses
- 🌐 Google search
- ▶️ YouTube control
- 💻 Open applications and websites
- 🕒 Date and time information
- 🔎 Web search
- 🖥️ Basic computer automation
- 🤖 Interactive Jarvis-style assistant

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- PyAutoGUI
- Webbrowser
- Requests
- Other Python libraries
